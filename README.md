# PXL Studio 🎨

Невелика браузерна студія малювання на чистих HTML, CSS та JavaScript. Інтерфейс перероблений під сенсорне керування і натхненний мобільними графічними редакторами: робоча зона по центру, швидкі інструменти та компактні панелі властивостей.

## Запуск

1. Розпакуй архів.
2. Відкрий `index.html` у сучасному браузері.
3. На телефоні можна відкрити той самий файл через локальний вебсервер або опублікувати папку на GitHub Pages.

Зовнішні бібліотеки, збірка та npm не потрібні.

## Можливості

### Малювання
- 14 пензлів: Pen, Pencil, Marker, Airbrush, Watercolor, Calligraphy, Pixel, Soft, Chalk, Ink, Flat, Glow, Crayon та Texture.
- Налаштування розміру, непрозорості й м'якості.
- Гумка, піпетка, заливка, лінія, прямокутник та еліпс.
- Живий попередній перегляд мазка під час руху вказівника.
- Підтримка миші, пера/стилуса та пальця.
- Інструмент тексту з вибором шрифту, розміру та жирності.
- Прямокутне виділення на активному шарі: копіювання, вирізання, вставлення, видалення та перетягування фрагментів.
- Історія останніх 12 кольорів зберігається локально в браузері / APK.

### Шари
- Додавання, дублювання, видалення й перейменування шарів.
- Переміщення шару вище/нижче.
- Видимість, блокування та непрозорість шару.
- Експорт з урахуванням порядку, видимості й непрозорості.

### Полотно та навігація
- Власна ширина й висота до 4096 × 4096 px.
- Пресети квадратного, портретного, альбомного та Story-формату.
- Зміна розміру зі збереженням вмісту по центру.
- Під час збільшення полотна фоновий шар автоматично заповнює нову площу базовим кольором — без прозорих смуг по краях.
- Поворот вмісту на 90° та дзеркальне відображення по X/Y.
- Окремий поворот вигляду полотна без зміни пікселів.
- Колесо миші — зум; Space + перетягування або середня кнопка — переміщення.
- Один палець на сенсорному екрані — малювання; два пальці — переміщення, масштабування та обертання вигляду.
- Вісь вертикальної симетрії по центру полотна з перемикачем у вкладці «Полотно».

### Файли
- Експорт зображення у PNG.
- Збереження редагованого проєкту у форматі `.pxl`.
- Відкриття `.pxl` проєктів та імпорт PNG/JPEG/WebP як окремого шару.
- Undo/Redo для малювання й основних операцій із шарами/полотном.

## Важливо

PXL Studio — аматорський браузерний редактор, а не повна заміна ibis Paint. Растрові шари, пензлі та трансформації реалізовані локально у браузері; великий розмір полотна й багато шарів можуть споживати помітний обсяг оперативної пам'яті.

### Попередній перегляд пензля

- Під час зміни розміру на полотні показується круглий курсор реального діаметра пензля; після зміни повзунка він з’являється в центрі аркуша.


## Android: автоматична перевірка оновлень через GitHub

Починаючи з updater-збірки PXL Studio, Android-застосунок перевіряє останній опублікований GitHub Release під час кожного запуску. Якщо версія релізу новіша за `PXL_APP_VERSION` у `paint.js`, з'являється вікно з нотатками та кнопкою завантаження APK. Якщо інтернету немає або GitHub тимчасово недоступний, редактор запускається звичайно.

### Перша збірка з updater

APK, наданий разом із цими файлами, має:
- `applicationId`: `com.htmltoapk.pxlstudio`
- Version name: `1.1`
- Version code: `2`
- Target SDK: `36`

У поточному APK не оголошено `android.permission.INTERNET`. Перед наступною збіркою в HTML to APK Builder відкрий налаштування дозволів і додай **Internet** (`android.permission.INTERNET`). Без цього WebView не зможе звертатися до GitHub.

Для першої збірки з механізмом оновлень встанови:
- Version name: `1.1.1`
- Version code: `3`
- Package name: залиш без змін — `com.htmltoapk.pxlstudio`
- Signing key: використай той самий ключ, яким підписано поточний APK.

У `paint.js` зараз стоїть `PXL_APP_VERSION = '1.1.1'`. Вона має збігатися з Version name цієї збірки.

### Як публікувати кожне наступне оновлення

1. Зміни `PXL_APP_VERSION` у `paint.js` на нову версію, наприклад `1.2.0`.
2. У HTML to APK Builder збільш Version name до `1.2.0`, а Version code — до `4`. Не змінюй Package name і підписний ключ.
3. Збери APK.
4. У GitHub створи Release з тегом `v1.2.0`, додай опис змін і прикріпи APK з точним ім'ям **`PXL-Studio.apk`**.
5. Після публікації релізу встановлені версії PXL Studio нижче `1.2.0` запропонують оновлення при наступному запуску.

Перевіряється останній опублікований, не чернетковий і не prerelease реліз репозиторію `ZoIman228/like-ibis`. Кнопка відкриває завантаження APK; встановлення потрібно підтвердити в Android. Автоматичного тихого встановлення немає.

**Підпис APK критично важливий:** якщо наступний APK підписати іншим ключем, Android не оновить ним встановлений застосунок поверх старого. Збережи ключ HTML to APK Builder і не перевстановлюй його зі скиданням даних/ключів.
